# BreathScribe v0.1.0

BreathScribe 是一款专注于高精度转写的桌面语音输入工具，全面支持本地离线推理与云端大模型语音识别。

## 核心特性

### 1. 双模云端语音识别（Cloud STT）

- **REST 批量识别**：集成 Google Gemini 3.5 专用语音转写模型（`gemini-3.5-transcribe`），录音结束后整段音频异步高精度转录。
- **WebSocket 实时流式识别**：集成 Gemini 3.5 Live API（`gemini-3.5-transcribe-live`），录音期间 16kHz PCM 音频实时分块推流，边说边实时出字。
- **离线与凭据防护**：未配置 API Key 或网络中断时快速失败，杜绝麦克风假死与静默丢字。

### 2. 本地离线语音识别

- 基于 Whisper 模型与 ggml 高性能张量推理引擎。
- 纯离线运行，保护数据隐私。

### 3. 全局网络代理管理

- 支持 System、HTTP、SOCKS5 代理模式。
- 内置即时连通性与往返延迟（RTT）测试。
- 免重启热重载，代理配置修改即刻生效。

### 4. 优化开屏引导

- 开屏向导支持跳过本地模型下载，直接配置云端 API Key 快速进入主界面。
- 系统托盘菜单支持云端转写与本地模型的快速切换。
