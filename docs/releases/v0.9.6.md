# BreathScribe v0.9.6

BreathScribe 是一款由开源项目 [cjpais/Handy](https://github.com/cjpais/Handy) 衍生、专注于桌面级高精度转写的语音输入工具。本项目在坚守对上游纯离线推理体系零破坏的前提下，全面接入了云端大模型语音识别能力，并完成了独立的视觉与品牌体系重塑。

## ✨ 核心特性更新

### 1. 独立品牌体系（BreathScribe）
- **全新视觉符号**：全面移除原版卡通小手 Logo 与图标，确立以“立体声波律动”与“云端速记底座”为核心的全新品牌视觉。
- **元数据与标识符**：客户端 App ID 统一为 `io.github.breathi3552.breathscribe`，程序命名全面切换为 `BreathScribe` / `breath-scribe.exe`。
- **合规独立**：遵循开源与知识产权规范，品牌资产与上游完全隔离。

### 2. 双模云端语音识别（Cloud STT）
- **REST 批量识别**：集成 Google Gemini 3.5 专用语音模型（`gemini-3.5-transcribe`），录音结束后整段音频异步高精度转录。
- **WebSocket 实时流式**：集成 Gemini 3.5 Live API（`gemini-3.5-transcribe-live`），录音期间 16kHz PCM 音频实时分块推流，实现边说边实时出字。
- **空凭据与离线安全守卫**：未配置 API Key 或断网时快速失败，杜绝麦克风假死与静默丢字。

### 3. 全局网络代理管理
- 支持 System、HTTP、SOCKS5 代理模式配置。
- 前端集成即时网络连通性与往返延迟（RTT）测试。
- 免重启热重载：网络配置修改即刻生效，无需重启桌面客户端。

### 4. 优化开屏向导与模型加载解耦
- **免本地模型冷启动**：开屏引导提供【跳过下载并配置云端】入口，无需预先下载数 GB 的本地 Whisper 模型即可即刻使用。
- **系统托盘同层互斥**：系统托盘菜单动态集成云端转写与本地离线模型互斥单选切换。

### 5. 平滑数据迁移机制
- 自动检测并迁移旧版 Handy / Handy-Cloud 的历史配置（`settings`）与转写记录数据库（`history.db`）。
- 本地模型目录优先使用 NTFS 硬链接（Hard Link），实现零磁盘额外占用的即时复用。
