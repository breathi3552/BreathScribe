## Welcome to BreathScribe

BreathScribe is a desktop speech-to-text application featuring both cloud models and high-performance local inference.

### Cloud Speech Recognition

- **Gemini 3.5 Transcribe (REST)**: Asynchronous high-accuracy transcription after recording stops.
- **Gemini 3.5 Transcribe Live (WebSocket)**: Real-time 16kHz PCM audio streaming with live text updates as you speak.

### Network Proxy Management

- Built-in System, HTTP, and SOCKS5 proxy configuration.
- Real-time connectivity and round-trip latency testing.
- Hot-reload without application restart.

### Local AI Models

- Local speech recognition powered by whisper and ggml.
- On-device processing when working offline.
